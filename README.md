# 樹木工作紀錄（PWA）

前線工人用手機 App（唔上架）：輸入**樹木號碼**、可選影樹牌／樹木資料、影**事前／事後**相，再分享俾公司同事。

線上：https://davychan188.github.io/epcem-app/

## 點用
1. 手機瀏覽器打開上述網址（建議加到主畫面）
2. 填樹木號碼 → 影事前／事後相（可選樹木資料相）
3. 撳「儲存並分享俾同事」→ 選 WhatsApp／電郵／Drive 等傳出

## 重要限制
- 而家紀錄先存在**該部手機**；分享先到公司同事。
- 未做自動雲端同步。下一步可接 Google Drive 共用資料夾或 Firebase。

## 本機預覽
```bash
python3 -m http.server 8080
```
